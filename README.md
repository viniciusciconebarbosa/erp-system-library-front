## 💻 Sobre a Interface
Esta aplicação é a interface gráfica do **Sistema ERP de Gerenciamento de Bibliotecas**. O projeto foi arquitetado de forma desacoplada, onde este Front-End consome a API RESTful desenvolvida em Java.

O objetivo desta interface é fornecer uma experiência de usuário (UX) fluida e responsiva para a administração da biblioteca, garantindo tipagem estática rigorosa e cobertura de testes.

## 🛠️ Tecnologias Utilizadas

* **Framework:** Next.js / React
* **Linguagem:** TypeScript *(Garantindo segurança e prevenção de erros em tempo de compilação)*
* **Estilização:** Tailwind CSS
* **Testes Automatizados:** Jest *(Testes unitários para garantir a integridade dos componentes)*
